# مرصد حائل | سلامة الطرق

لوحة عربية تجريبية لرصد الحفر ومتابعة حالة الطرق في مدينة حائل.

## تعديل الموقع

- افتح `index.html` من المستودع واضغط زر القلم لتحريره مباشرة، أو نزّل المستودع وافتح الملف في Visual Studio Code.
- الصفحة مبنية في ملف واحد باستخدام HTML وCSS وJavaScript.
- البلاغات المدخلة تُحفظ محليًا في المتصفح عبر LocalStorage.

## تنبيه

الخريطة والنقاط والبلاغات بيانات تجريبية؛ الموقع غير متصل ببيانات أمانة حائل أو ببلاغات ميدانية مباشرة.
