# مرصد حائل | سلامة الطرق

لوحة تجريبية لرصد الحفر ومتابعة حالة الطرق في مدينة حائل.

## النسخة الثابتة

ملفات الموقع التي يمكن فتحها مباشرة من المستودع: `index.html` و`styles.css` و`app.js`.

## نسخة Python المحلية

توجد نسخة بخادم Python وقاعدة بيانات SQLite في مجلد `python-app`. اتبع تعليمات التشغيل في [دليل نسخة Python](python-app/README.md). تستخدم Python القياسية ولا تحتاج تثبيت مكتبات خارجية.

واجهة المتصفح في النسختين تستخدم HTML وCSS وJavaScript، ويشغّل Python الخادم ويحفظ البلاغات محليًا في SQLite.

## تنبيه البيانات

الخريطة والبلاغات الأولية للتجربة فقط، ولا تتصل ببيانات أمانة حائل أو ببلاغات ميدانية مباشرة.
