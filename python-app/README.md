# مرصد حائل بنظام Python

نسخة محلية من لوحة رصد الحفر، تعمل بخادم Python من دون مكتبات إضافية. الواجهة في المتصفح تستخدم HTML وCSS وJavaScript، بينما Python يقدم الصفحة وواجهات البلاغات، وتُحفظ البيانات في قاعدة SQLite محلية.

## التشغيل

1. ثبّت Python 3.10 أو أحدث.
2. افتح الطرفية داخل مجلد `python-app`.
3. شغّل:

   ```bash
   python3 app.py
   ```

4. افتح `http://127.0.0.1:8000` في المتصفح.
5. لإيقاف الخادم اضغط `Ctrl+C` في الطرفية.

تُخزّن البلاغات في `data/reports.sqlite3` وتبقى بعد إغلاق البرنامج. الخريطة والبلاغات الأولية توضيحية وتجريبية، وليست بيانات ميدانية أو اتصالًا بأمانة حائل.
